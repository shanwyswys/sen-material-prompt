# 角色與任務目標
你是一位專業的幼兒特殊教育科技設計師。請根據以下規格，製作適用於個別訓練室的平板觸控互動小遊戲（HTML5 / Web App 規格）：

# 教材背景資訊
- 對象年齡：4歲
- 核心需要：時間序列概念（理解並運用「今日 / 尋日 / 聽日」）
- 實施情境：個別訓練室（導師一對一輔導）
- 學習目標：學生能按廣東話簡短語音提示與圖示，正確辨識、拖曳及說出「今日」、「尋日」、「聽日」對應的事件與時間軸。
- 媒介形式：平板觸控小遊戲（單次互動畫面，支援大圖示拖曳／點擊判定）
- 語言規則：廣東話口語指令，每句長度嚴格控制在 3 至 5 字以內，必須配合圖示。
- 視覺規則：高清晰度真實物品去背圖，純白或淺灰素色背景，大按鈕、高對比，避免視覺干擾。
- 禁止元素：嚴禁快節奏倒數計時、突發性強烈音效、閃爍特效、複雜背景及細小點擊判定區。

# 畫面與互動架構
1. 界面佈局：
   - 頂部時間軸：三格水平排列的大型車廂（由左至右：尋日 [上一站]、今日 [現在站 - 粗黃色外框標示]、聽日 [下一站]）。
   - 底部操作區：三張高解析度去背真實物品圖卡（積木、雨傘、生日蛋糕）。
2. 互動流程：
   - 步驟一（理解「今日」）：播放語音「今日玩積木」（5字），中央「今日」車廂微幅放大提示，幼兒將積木拖入中央車廂。
   - 步驟二（理解「尋日」）：播放語音「尋日落大雨」（5字），左方車廂提示，幼兒將雨傘拖入左方「尋日」車廂。
   - 步驟三（理解「聽日」）：播放語音「聽日食蛋糕」（5字），右方車廂提示，幼兒將蛋糕拖入右方「聽日」車廂。
3. 回饋與鷹架機制：
   - 正確配對：發出溫和提示音，車廂顯示綠色勾號，觸發仿說引導提示（如畫面文字提示導師：「係今日！」）。
   - 配對錯誤：圖卡平滑彈回原位，無扣分或負面音效，提供重複嘗試機會。
